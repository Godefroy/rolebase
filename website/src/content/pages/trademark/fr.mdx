# Politique de marque

*Dernière mise à jour : 2026-11-06.*

ROLEBASE est une marque déposée à l’INPI sous le numéro 4982809. Elle appartient à Godefroy de Compreignac. GDFR, la société qui édite Rolebase, l’exploite. Le nom et le logo identifient le logiciel publié sur [github.com/Godefroy/rolebase](https://github.com/Godefroy/rolebase) et le service hébergé sur [rolebase.io](https://rolebase.io/fr).

Le code de Rolebase est libre. Sa licence, disponible dans le dépôt, vous donne le droit d’utiliser, de modifier et de redistribuer le code, mais aucun droit sur le nom ni sur le logo. Cette politique protège les personnes qui choisissent Rolebase : quand elles voient le nom, elles savent qu’elles utilisent la version maintenue par l’équipe Rolebase.

## Usages autorisés sans demander

- Parler de Rolebase dans un article, une formation, une conférence ou un post, et faire un lien vers le site ou le dépôt.
- Dire que votre produit est « basé sur Rolebase » ou qu’il est « un fork de Rolebase », à condition que son nom soit différent.
- Accompagner des organisations qui utilisent Rolebase, et l’écrire dans vos offres (« accompagnement à la gouvernance partagée avec Rolebase »).
- Installer Rolebase pour les besoins internes de votre organisation, en gardant le nom Rolebase.
- Utiliser le logo, sans le modifier, pour illustrer un contenu sur Rolebase.

## Usages soumis à un accord écrit

- Utiliser « Rolebase », ou un nom proche, dans le nom d’un produit, d’un service ou d’une entreprise, ou dans un nom de domaine.
- Proposer à des tiers une version hébergée, gratuite ou payante, sous le nom ou avec le logo Rolebase.
- Vous présenter comme partenaire ou revendeur de Rolebase, ou présenter votre produit comme une version officielle.
- Modifier le logo ou en créer une variante.

## Les forks

Un fork que vous distribuez ou que vous hébergez pour d’autres organisations doit porter un autre nom et un autre logo. Remplacez le nom et le logo Rolebase dans l’interface, les emails et la documentation. Gardez les mentions de droit d’auteur et de licence, comme l’exige la licence du code. Vous pouvez toujours écrire que votre produit est basé sur Rolebase.

Si vous accompagnez des organisations et souhaitez proposer Rolebase à vos clients, la page [partenaires](/fr/partners) décrit comment travailler ensemble. En devenant partenaire, vous laissez la maintenance du logiciel à l’équipe Rolebase. Vos clients profitent ainsi des nouvelles versions dès leur sortie.
