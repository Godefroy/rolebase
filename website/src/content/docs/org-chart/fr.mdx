## Présentation

L'organigramme interactif est le moyen principal de visualiser votre structure organisationnelle. Il affiche les rôles sous forme de conteneurs imbriqués, où un rôle contenant des sous-rôles représente une équipe ou un département, ou sous forme d'arborescence classique de haut en bas si vous préférez cette lecture. Vous pouvez :

- **Cliquer** sur un rôle pour zoomer et voir ses sous-rôles.
- **Glisser** pour naviguer dans l'organigramme.
- **Défiler** pour zoomer et dézoomer.
- Basculer entre les vues à l'aide du sélecteur de vue.
- Utiliser la **mini-carte** affichée en bas à droite sur ordinateur, qui situe votre position dès que l'organigramme dépasse l'écran, et cliquer ou glisser dessus pour vous déplacer.
- **Cliquer droit** sur un rôle, un membre ou le fond pour ouvrir le menu des actions disponibles à cet endroit (voir ci-dessous).

Essayez sur l'organisation d'exemple ci-dessous : cliquez un rôle pour zoomer sur ses sous-rôles, glissez pour naviguer, et défilez pour zoomer.

## Menu du clic droit

Un clic droit ouvre les actions disponibles à l'endroit cliqué, sans quitter l'organigramme :

- Sur un **rôle**, les actions de son panneau : le modifier, le déplacer dans un autre rôle, le dupliquer, l'exporter, le transformer en rôle de base ou l'en séparer, et l'archiver. Le déplacement et la duplication ouvrent un formulaire où vous choisissez le rôle de destination.
- Sur un **membre**, le retirer du rôle dans lequel vous avez cliqué.
- Sur le **fond**, les options de l'organigramme : raccourcis, rôles de base, rôles vacants, [historique](/fr/docs/history) et partage. Chacune s'ouvre dans un panneau à côté de l'organigramme.

Chaque menu ne propose que ce que votre [mode de gouvernance](/fr/docs/governance-modes) et vos droits autorisent.

## Vues

L'organigramme propose trois vues, que vous pouvez replier autour du rôle sélectionné et afficher avec ou sans les membres. Vous pouvez définir la vue par défaut dans les [paramètres de l'organisation](/fr/docs/organizations), et changer de vue à tout moment à l'aide du sélecteur.

| Vue                    | Description                                                                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cercles**            | Affiche tous les rôles imbriqués les uns dans les autres. La taille de chaque rôle dépend du nombre de sous-rôles et de membres qu'il contient. |
| **Arbre hiérarchique** | Affiche tous les rôles en organigramme de haut en bas, chaque rôle dans une carte reliée à son rôle parent, avec les membres qui l'occupent.    |
| **Trombinoscope**      | Affiche d'un coup d'œil tous les membres de l'organisation, sans les rôles.                                                                     |

### Replier la vue

L'option **Replié**, dans le sélecteur de vue, s'applique aux vues **Cercles** et **Arbre hiérarchique**. Elle n'affiche que le rôle sélectionné, ses rôles parents et leurs rôles directs, à la même taille, plutôt que toute l'organisation. Sur une grande organisation, c'est ce qui garde la lecture confortable. Dans l'**Arbre hiérarchique**, un rôle replié affiche ses représentants, et vous découvrez ses membres en l'ouvrant.

### Afficher les membres

L'option **Afficher les membres**, dans le sélecteur de vue, est cochée par défaut : chaque rôle liste les membres qui l'occupent. Décochez-la pour lire la structure seule. Les membres disparaissent alors de l'organigramme et ne réservent aucune place : les rôles se resserrent d'autant. Ce réglage s'applique aux vues **Cercles** et **Arbre hiérarchique**, et se retrouve dans l'export en image.

### Arbre hiérarchique

La vue **Arbre hiérarchique** présente la même structure sous la forme d'organigramme descendant, celle à laquelle la plupart des organisations sont habituées. Chaque rôle occupe une carte, reliée à son rôle parent par un trait, et les membres apparaissent dans la carte du rôle qu'ils occupent.

Toutes les interactions restent identiques à la vue en cercles : cliquer sur un rôle pour l'ouvrir, glisser-déposer pour déplacer un rôle ou un membre, zoomer et naviguer librement.

## Partage (lien et embed)

Le partage publie une page publique de votre organigramme, consultable par toute personne disposant du lien, sans compte Rolebase. Les administrateurs de l'organisation l'ouvrent depuis le bouton de réglages au-dessus de l'organigramme, ou depuis le menu du clic droit sur le fond, puis activent **Activer le partage**.

Le panneau sépare deux décisions. Dans **Paramètres de publication**, la page publique reprend les noms et les raisons d'être des rôles, et **Publier les membres** y ajoute les membres avec leurs noms et leurs photos uniquement. Ce réglage est enregistré sur l'organisation et s'applique à tous vos liens ; le reste demeure privé.

Dans **Paramètres du lien**, vous choisissez la vue sur laquelle la page s'ouvre, la possibilité pour les visiteurs de zoomer et de se déplacer, et un fond transparent pour se fondre dans votre propre site. Ces réglages sont contenus dans l'adresse, donc vous pouvez créer plusieurs liens avec des réglages différents. Le panneau vous donne un lien à partager et un code iframe pour intégrer l'organigramme dans une page de votre site.

Désactiver **Activer le partage** retire aussitôt la page publique.
