## Présentation

L'organigramme interactif est le moyen principal de visualiser votre structure organisationnelle. Il affiche les rôles sous forme de conteneurs imbriqués, où un rôle contenant des sous-rôles représente une équipe ou un département, ou sous forme d'arborescence classique de haut en bas si vous préférez cette lecture. Vous pouvez :

- **Cliquer** sur un rôle pour zoomer et voir ses sous-rôles.
- **Glisser** pour naviguer dans l'organigramme.
- **Défiler** pour zoomer et dézoomer.
- Basculer entre les vues à l'aide du sélecteur de vue.

## Vues

L'organigramme propose six vues différentes. Vous pouvez définir la vue par défaut dans les [paramètres de l'organisation](/fr/docs/organizations), et basculer entre les vues à tout moment à l'aide du sélecteur.

| Vue                       | Description                                                                                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tous les Rôles**        | Affiche la hiérarchie complète de tous les rôles et sous-rôles. La taille de chaque rôle dépend du nombre de sous-rôles et de membres qu'il contient. |
| **Holarchie**             | Affiche à la même taille les sous-rôles du rôle sélectionné, avec les membres qui les représentent.                                                   |
| **Hiérarchique**          | Affiche tous les rôles en organigramme hiérarchique de haut en bas, chaque rôle dans une carte reliée à son rôle parent, avec les membres qui l'occupent. |
| **Hiérarchique replié**   | Affiche le même organigramme recentré sur le rôle sélectionné, avec ses rôles parents, ses rôles directs et les membres qui les occupent.             |
| **Opérationnel**          | Affiche tous les rôles à un même niveau, mélangés, avec les membres qui les représentent.                                                             |
| **Membres uniquement**    | Affiche l'organisation du point de vue des membres.                                                                                                   |

### Vues hiérarchiques

Les vues **Hiérarchique** et **Hiérarchique replié** présentent la même structure sous la forme d'organigramme hiérarchique descendant, celle à laquelle la plupart des organisations sont habituées. Chaque rôle occupe une carte, reliée à son rôle parent par un trait, et les membres apparaissent dans la carte du rôle qu'ils occupent.

Toutes les interactions restent identiques aux vues en cercles : cliquer sur un rôle pour l'ouvrir, glisser-déposer pour déplacer un rôle ou un membre, zoomer et naviguer librement.

<OrgChartView demo="demo" view="HierarchyAll" height="440px" />

Sur une grande organisation, l'organigramme complet devient large. La vue **Hiérarchique replié** garde alors la lecture confortable en n'affichant que la ligne des rôles parents et les rôles directs du rôle sélectionné.

<Callout type="tip" title="Navigation">
  Quelle que soit la vue par défaut, les utilisateurs peuvent toujours basculer
  entre les vues et cliquer sur n'importe quel rôle pour explorer son contenu.
  La vue courante figure dans l'adresse de la page, donc un lien partagé ouvre
  l'organigramme dans la vue et sur le rôle que vous aviez à l'écran.
</Callout>
